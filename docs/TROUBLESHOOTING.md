# Troubleshooting

Start with **`pnpm run doctor`**. It checks versions, env vars, Supabase reachability, migrations and sign-in providers without printing secrets. (`pnpm doctor` without `run` is pnpm's own built-in command, which checks pnpm, not this app.)

| Symptom                                                      | Likely cause                                                            | Fix                                                                                                                               |
| ------------------------------------------------------------ | ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Login page says "Supabase isn't configured"                  | `NEXT_PUBLIC_SUPABASE_URL` / `_PUBLISHABLE_KEY` missing                 | Copy them from `pnpm exec supabase status` into `.env.local`, then restart `pnpm dev`                                             |
| `pnpm db:start` fails: "Cannot connect to the Docker daemon" | Docker isn't running                                                    | Start Docker Desktop, then retry                                                                                                  |
| `pnpm db:start` fails: port already in use                   | Another Supabase project is running                                     | `pnpm exec supabase stop --project-id <other>`, or change ports in `supabase/config.toml`                                         |
| doctor: "database is behind"                                 | New migrations not applied                                              | Local: `pnpm exec supabase migration up` (keeps data) or `pnpm db:reset` (wipes it). Hosted: `pnpm exec supabase db push`         |
| Confirmation link says "invalid or has expired"              | Link opened in a different browser, already used, or expired            | Sign in normally (the email is already confirmed), or request a new link. Links must be opened in the browser that asked for them |
| Confirmation / reset email points to the wrong host          | `NEXT_PUBLIC_SITE_URL` is wrong, or the URL isn't allowed in Supabase   | Fix the env var (then rebuild), and add `https://your-domain/**` to Supabase Auth → Redirect URLs                                 |
| No emails arrive locally                                     | Expected: nothing is really sent locally                                | Open Mailpit at http://127.0.0.1:54324                                                                                            |
| Welcome email never sent                                     | `EMAIL_TRANSPORT=log` (the default)                                     | Set `smtp` or `resend`; see docs/EMAIL_AND_ANALYTICS.md. Check server logs for `[email:…] send failed`                            |
| "Continue with GitHub" errors on the provider page           | Provider disabled in Supabase, or a wrong callback URL in the OAuth app | doctor shows which provider; use callback `…/auth/v1/callback` (docs/AUTH_SETUP.md)                                               |
| No cookie banner                                             | Expected unless `NEXT_PUBLIC_GA_MEASUREMENT_ID` is set                  | Plausible is cookieless and needs no banner                                                                                       |
| Changed a `NEXT_PUBLIC_*` value but the site didn't change   | They're compiled in at build time                                       | Restart `pnpm dev`, or rebuild/redeploy                                                                                           |
| "Too many attempts" on sign-in                               | Per-IP rate limit (in memory)                                           | Wait a few minutes. It resets when the server restarts                                                                            |
| `pnpm test:e2e` fails at startup                             | Local Supabase not running, or Chromium not installed                   | `pnpm db:start`; `pnpm exec playwright install chromium`                                                                          |
| Playwright: "strict mode violation", two matching fields     | Next 16 keeps the previous page mounted but hidden                      | Use `getByRole(...)` or `.filter({ visible: true })`                                                                              |
| Server log: "unstable value `Date.now()` while prerendering" | Request-time code outside `<Suspense>` / missing `connection()`         | Read the session inside a Suspense boundary; the Supabase server client already calls `connection()`                              |
