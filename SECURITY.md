# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub's **Security → Report a vulnerability** on this repository. Include steps to reproduce, the affected version, and the impact you expect.

We aim to acknowledge reports within 5 business days. This is a small open-source project, so response times are best effort, not a guarantee.

## Supported versions

Only the latest release on the default branch receives security fixes.

## Scope

This is a starter template. Once you clone it, your deployed app, its configuration and its credentials are yours to secure. Reports about the template's own code and documentation are in scope.
