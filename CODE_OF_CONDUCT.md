# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and constructive. Critique ideas, not people.
- No harassment, discrimination, sexualized content, personal attacks or doxxing.
- Assume good faith and help newcomers.

## Enforcement

Report unacceptable behaviour privately to the maintainers. Until a dedicated address is published, use GitHub's private vulnerability reporting form for this repository, or contact a maintainer directly through their GitHub profile. Reports are handled confidentially. Maintainers may remove content, or warn, suspend or ban participants, as described in the Contributor Covenant enforcement guidelines.
